# 任务总览维护
任务文档 `TASKS.md` 旁有一份同目录的 `overview.yaml`，用思维导图的形式展示任务关联的独立改动点及其代码对象。任务内容和状态以 `TASKS.md` 为准，总览只引用任务 ID。

## 何时触发
本轮满足以下任一条件时，在结束 turn 之前异步拉起一次总览维护：
- 新建、删除了任务：任务条目的变化，很显然会影响任务的作用范围；
- 更新、迭代任务或代码：实际改动点、改动描述、关联任务或代码对象发生变化时；

同一改动持续迭代时更新已有改动点的描述；没有实际变化时无需维护。

## 如何调用
使用 task-overview 异步调用，无需关注subAgent返回，告知总览图会自动更新即可，`prompt` 里写清需要维护涉及的任务列表。

## 注意
- `changes` 字段一般由子 Agent 维护，使用 `code-review` skill 时按审查指导更新分析，避免并发写入同一文档。
- 触发后无需等待子 Agent 结束，直接继续后续步骤。
