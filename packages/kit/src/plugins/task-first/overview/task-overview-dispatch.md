# 任务总览维护
任务文档 `TASKS.md` 旁有一份同目录的 `overview.yaml`，用思维导图的形式展示全局入口、页面、组件与任务的关联。任务内容和状态以 `TASKS.md` 为准，总览只引用任务 ID。

## 何时触发
本轮满足以下任一条件时（任务条目变化、任务的本身的作用范围变化），在结束 turn 之前异步拉起一次总览维护：
- 新建、删除了任务：任务条目的变化，很显然会影响任务的作用范围；
- 更新、迭代任务：任务的作用范围发生变化，影响了任务归属的组件和页面时；

注意：任务的作用范围发生了变化，才需要维护，比如我在一个任务里，反复修改颜色值，还是属于那一个组件，无需迭代 overview 文档。

## 如何调用
使用 task-overview 异步调用，无需关注subAgent返回，告知总览图会自动更新即可，`prompt` 里写清需要维护涉及的任务列表。

## 注意
- 总览由子 Agent 维护，不要自己读写 `overview.yaml`。
- 触发后无需等待子 Agent 结束，直接继续后续步骤。
