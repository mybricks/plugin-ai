


## 主题变量

### 浅色模式
```css
:root {
  --mybricks-color-primary: #FA6400;
  --mybricks-text-color-main: #333;
  --mybricks-text-color-hover: #FFF;
  --mybricks-text-color-active: #FFF;
  --mybricks-text-color-disabled: #AAA;
  --mybricks-bg-color-main: #FFF;
  --mybricks-bg-color-main-transparent: rgba(255, 255, 255, 0.93);
  --mybricks-bg-color-secondary: #F5F5F5;
  --mybricks-bg-color-hover: #FDFDFD;
  --mybricks-bg-color-active: #EEE;
  --mybricks-bg-color-designer: #F5F5F5;
  --mybricks-menu-bg-color: #FFF;
  --mybricks-shadow-main: rgba(0, 0, 0, 0.2) 0 0 5px;
  --mybricks-shadow-main-left: rgba(0, 0, 0, 0.2) -3px 0px 5px;
  --mybricks-shadow-for-border: none;
  --mybricks-border-color-main: #E6E6E6;
  --mybricks-border-color-secondary: #F5F5F5;
}
```

### 深色模式
```css
{
  :root {
    --mybricks-text-color-main: #FFF;
    --mybricks-text-color-hover: #FFF;
    --mybricks-text-color-active: #FFF;
    --mybricks-text-color-disabled: #CCC;
    --mybricks-bg-color-main: #292929;
    --mybricks-bg-color-main-transparent: rgba(0, 0, 0, 0.8);
    --mybricks-bg-color-secondary: #383838;
    --mybricks-bg-color-hover: #494949;
    --mybricks-bg-color-active: #494949;
    --mybricks-bg-color-designer: --mybricks-bg-color-main;
    --mybricks-menu-bg-color: #1E1E1E;
    --mybricks-shadow-main: 0px 3px 8px rgba(0, 0, 0, 0.35), 0px 1px 3px rgba(0, 0, 0, 0.5), inset 0px 1px 0px rgba(255, 255, 255, 0.1), inset 0px 0px 1px rgba(255, 255, 255, 0.5);
    --mybricks-shadow-main-left: rgba(255, 255, 255, 0.8) -1px 0px 4px;
    --mybricks-shadow-for-border: 0px 3px 8px rgba(0, 0, 0, 0.35), 0px 1px 3px rgba(0, 0, 0, 0.5), inset 0px 1px 0px rgba(255, 255, 255, 0.1), inset 0px 0px 1px rgba(255, 255, 255, 0.5);
    --mybricks-border-color-main: #444;
    --mybricks-border-color-secondary: #444;
  }
}

```
